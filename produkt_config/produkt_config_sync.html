Produkt-Config · Sync

Firestore: prüfe…

📥 Import — Datei → Firestore

JSON-Array mit Produkt-Stammdaten hochladen (jedes Element braucht legacyKey). Schreibt jedes Produkt als eigenes Dokument, Dokument-ID = legacyKey. Last-Write-Wins — bestehende Dokumente mit gleicher ID werden überschrieben, sonst bleibt alles unberührt.

📤 Export — Firestore → Datei

Lädt den aktuellen Stand aus Firestore und erzeugt eine produkt_config.json zum Download. Diese Datei danach manuell im Repo ersetzen (GitHub-Weboberfläche reicht) — erst dann sehen die Lese-Satelliten (Froster-Inventur, NFC-Stationen, mega_erfassung …) die Änderung.
